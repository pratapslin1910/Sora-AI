# SORA Chrome Automation Extension

This extension provides browser automation tools for SORA:

- **chrome_search_and_navigate**: Search Google or navigate to any web URL.
- **chrome_manage_tabs**: Open, switch, and manage Chrome tabs.
- **chrome_manage_windows**: Open standard windows and Incognito private browsing windows.
- **chrome_interact_page**: Extract titles and readable text from target pages.

## Permissions Required
- `browser`
- `network`
