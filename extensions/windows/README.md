# SORA Windows Automation Extension

Provides native Windows operating system automation capabilities for SORA:

- **windows_launch_app**: Launch executables and desktop applications.
- **windows_close_app**: Terminate running application processes.
- **windows_open_settings**: Directly navigate to Windows Settings pages (`apps`, `network`, `display`, `bluetooth`, `windowsupdate`, etc.).
- **windows_file_explorer**: Open directories, highlight files, or search paths in Windows File Explorer.

## Permissions Required
- `apps`
- `files`
